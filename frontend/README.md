# Frontend (Next.js)

The web app: landing page, sign-in, copilot, dashboard and account pages.
Setup, configuration and commands are in the [main README](../README.md).

- Pages: `src/app/`
- Live session (audio capture, connection, reconnect): `src/hooks/useCopilotSession.ts`
- API client: `src/lib/api.ts`
- Branding (name, text, colours): `src/config/brand.ts`
